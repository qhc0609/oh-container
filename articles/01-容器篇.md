# 电脑不能上网，又想用大模型？我拿手机当跳板，搞定了

上个月我去一家工厂做实施。客户的工控机出了毛病，他想让我用大模型帮着看一眼报警日志。

我点开那台机器的浏览器，连百度都打不开——它压根没联网。这是车间的安全规定，机器不准接外网。

可我手里的 AI 工具全在云上。手机倒有信号，但你就让我在六寸屏幕上，给大模型敲一整份几千行的报错日志？

那天晚上我越想越不对：手机有网，但算不动大模型，屏幕也小；电脑能算、键盘也舒服，偏偏不能上网。

那能不能……让电脑当"大脑"负责打字和看结果，手机当"传声筒"去云上跑一趟，把答案带回来？

后来我真把它做出来了：一根 USB 线把手机插到那台断网的工控机上，敲一个词，屏幕上就蹦出了 DeepSeek 的回答。**断网的电脑，第一次"用上了云"。**

---

## 一、先说清楚：这不是玄学，是两个死穴拼成了活路

很多人卡在 AI 面前，其实是卡在"网络"和"算力"这两件事上，而且往往只占一样：

- 你在家，电脑能上网，但你想跑个本地大模型，显卡带不动，风扇狂转还卡死。
- 你在车间、在保密室、在出差的破酒店，电脑压根没网，云上的大模型再强也够不着。

而我碰上的，是两样都占：电脑不能上网，手机又有网但伺候不了大模型。

转机在一个反直觉的念头：**既然手机有网、电脑有键盘，那就别让电脑自己上网，也别让手机自己算——让 AI 客户端住在手机里（它只负责转发，不负责算），电脑通过 USB 线"遥控"它。**

手机不费算力，电脑不需要网。两个缺点，拼成了一个优点。

---

## 二、说人话：这套方案到底干了啥

先泼盆冷水：手机里不能直接装个 Windows 版 Claude。手机是 ARM 架构的 OpenHarmony 系统，跟电脑不是一回事。

我们的做法是，在手机存储里隔出一个"小房间"（专业叫容器，但别被词吓到，它其实就是手机里的一个独立 Linux 小世界），把 AI 客户端塞进去，再让电脑通过数据线进到这个房间里敲命令。

画成一句话：

> 电脑的键盘 → USB 线 → 手机里的小房间 → 手机的网络 → 云端 DeepSeek → 答案原路返回屏幕

整个过程，那台工控机自己一次网都没连。它只跟手机这根线说话。

对保密环境反而是好事——敏感机器始终物理离线，只有你愿意拷过去的内容，才会经手机走到云上。

---

## 三、手机里那个"小房间"长啥样

这个小房间，是用我们自写的、只有 10KB 的小工具（叫 `ohc`）圈出来的。它没用 Docker——后面讲原理时会说为什么手机跑不了 Docker——而是在手机里装了一套超轻量的 Linux（Alpine），再往里放了几样东西：

- **Node.js**：AI 客户端跑在它上面
- **Claude Code**：Anthropic 出的 AI 编程助手
- **OpenCode**：另一个 AI 客户端，下一篇会讲它的免费档
- **ripgrep**：帮 AI 在代码里飞快搜东西

整套塞在手机 `/data` 分区，**不到 1GB**。对现在动辄 256GB 的手机来说，九牛一毛。

---

## 四、手把手：从零到能用（就折腾这一次）

先说清楚：第一次搭建要花你二三十分钟，之后每天就是插根线、敲一个词。就像装一次打印机驱动，往后天天用。

你需要：

1. 一台 OpenHarmony 手机（能开"USB 调试"）
2. 一根数据线，一台 Windows 电脑
3. 你自己的 DeepSeek API Key（新用户几块钱额度够玩很久；后面文章我会算账）

**第一步，把项目弄到电脑上：**

```sh
git clone https://github.com/qhc0609/oh-container
cd oh-container
```

**第二步，一根线把整套环境推到手机：**

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1 -Key 你的DeepSeekKey -OcKey 你的OpenCodeKey
```

这个脚本会自动把运行时、AI 客户端、配置全送进手机，最后自己校验。两个 Key 分别对应两款 AI 客户端，下两篇文章细说；只想先用一个，另一个可以先不填。

> 小提示：第一次搭建时，手机里还缺一样东西——那个"小房间"本身（rootfs）。项目里 `docs/build-rootfs.md` 写了完整步骤，照着敲就行。它是最费劲的一步，但只做一次；后面我会单独写一篇，把从零拼出这个房间的每个螺丝钉都摊开讲。

**第三步，等它跑完。** 脚本最后会告诉你"部署完成"。就这三步，剩下的全是手机和线在干活。

---

## 五、以后每天怎么用（这才是重点）

搭好之后，日常使用简单到不好意思叫"教程"：

把手机插上电脑，打开电脑的命令行，输入：

```sh
hdc shell
```

进到手机根目录，再敲：

```sh
claude
```

回车。屏幕上出现 DeepSeek 的欢迎语——**成了**。你在这台断网的电脑上，正用着云端的 DeepSeek。

想换另一款免费客户端，把 `claude` 换成 `opencode` 就行。

不用装任何电脑端软件，不用给电脑开热点，不用折腾网卡。线一插，词一敲，完事。

---

## 六、底层原理一句话（不爱折腾可跳过）

你肯定想问：手机里怎么凭空变出个 Linux？其实 Linux 内核天生能把一个目录"假装"成整台机器的根目录（这叫 `chroot`），再配一点命名空间做隔离，就圈出一块独立空间。OpenHarmony 的内核是裁剪过的，不像服务器支持全套隔离——它缺了 PID 和 user 两种，所以现成的 Docker 跑不起来，我们才写了那个 10KB 的 `ohc` 自己干。源码全在 GitHub，爱钻研的去翻；不爱看的，记住"插线敲词"四个字就够了。

## 七、它能解决哪些真问题

别只当玩具。这套路子，正经能扛活：

- **车间工控机**：机器按规矩不能联网，但老师傅想让 AI 帮看报警日志、改一段控制逻辑、写份交接报告。
- **保密 / 受限环境**：电脑严禁接外网，但允许接手机调试线——数据只在这根线里走。
- **出差破酒店**：电脑连的 WiFi 烂到云页面都刷不出，手机信号却满格。
- **宿舍 / 访客网络**：学校或公司 Guest 网络限制一堆，网页版 AI 打不开，但你能插手机。

说白了，只要"手机有网 + 电脑有键盘"同时成立，这台电脑就能用上云大模型——**不管它本身多么与世隔绝。**
