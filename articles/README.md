## 封面与排版

**封面**：不要用 AI 生成的科技感图。用真实截图——`hdc shell` 里敲 `claude`、终端里出现 DeepSeek 回答的那一屏。真实截图的可信度远高于设计图。

**开头三段**：必须在前三行给出结果或冲突。微信读者滑走只需要 0.5 秒。

**代码块**：全部用可复制的纯文本，不要截图代码。读者要复制。

**段落**：一段不超过三行。手机屏幕窄，长段落直接劝退。

**加粗**：克制。每节最多两处，只加在"反直觉的结论"上。
